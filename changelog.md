# Changelog

All notable changes, formula/cask updates, and release history for Homebrew-BrewStore are documented in this file.

---

## [1.0.0] - Initial Production Cask Release

### Added

- **BrewStore Cask Distribution**: Added `brewstore` cask (`casks/brewstore.rb`) enabling 1-command installation via Homebrew (`brew install --cask brewstore`).
- **Checksum Verification**: SHA-256 integrity verification for production DMG artifacts.
- **Tap Repository Infrastructure**: Established automated tap distribution channels for BrewStore.
